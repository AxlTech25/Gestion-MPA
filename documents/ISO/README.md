# ISO — normas de referencia y plantillas

Los PDF de **ISO 9000:2015** e **ISO 9001:2015** son material de consulta del tesista. No se commitean (derechos de ISO). Las **plantillas operativas** del caso Sigemad sí van al repositorio.

| [06_calidad/](../06_calidad/) | Fase 06: pruebas estáticas (SonarQube) y evidencia de calidad |
| [Anexo 07 A7-6](../Intervencion%20metodologica%20y%20plan%20de%20tesis/Anexo07_Plantillas_Figuras_Tablas.md) | Tabla y figura de procesos para el Word de tesis |

Jerarquía que usa la matriz V4:

```text
Macroproceso (MP) → Procedimiento (PR) → Actividad (ACT) → Función (F-NNN)
```

El **prompt del procedimiento** (columna V4) es el que asiste el diagrama Bizagi, no el prompt I-* del código.
