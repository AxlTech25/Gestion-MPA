# Plantilla — control de información documentada (ISO 9001 cl. 7.5)

Una ficha por documento controlado (procedimiento, política, plan de pruebas, matriz). No sustituye a Git: el SHA es la evidencia de versión.

---

## Identificación

| Campo | Contenido |
|-------|-----------|
| **ID documento** | DOC-NNN |
| **Título** | |
| **Tipo** | Procedimiento / Plantilla / Plan / Registro / Política |
| **Ubicación** | Ruta en el repo |
| **Versión vigente** | |
| **SHA o tag** | |
| **Dueño** | |
| **Revisor** | |
| **Fecha de vigencia** | YYYY-MM-DD |
| **Próxima revisión** | YYYY-MM-DD |

## Distribución y acceso
