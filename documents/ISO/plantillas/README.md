# Plantillas ISO 9001 — Sigemad MPA

Fichas para documentar el sistema de procesos (ISO 9001:2015 cl. 4.4 y 7.5). Una ficha por código. Copiar, renombrar y rellenar. El inventario vigente está en [inventario_procesos.md](./inventario_procesos.md).

| Plantilla | Código | Cláusula de ancla | Cuándo usarla |
|-----------|--------|-------------------|---------------|
| [plantilla_macroproceso.md](./plantilla_macroproceso.md) | MP-NN | 4.4 | Un proceso de primer nivel (patrimonio TI, mantenimiento, gobernanza) |
| [plantilla_procedimiento.md](./plantilla_procedimiento.md) | PR-NN-NN | 8.1 / 8.5 | Un procedimiento operativo (registrar equipo, intervenir, autenticar) |
| [plantilla_actividad.md](./plantilla_actividad.md) | ACT-NN-NN-NN | 8.5 | Una actividad que agrupa una o más funciones F-* |
| [plantilla_control_documentos.md](./plantilla_control_documentos.md) | DOC-NNN | 7.5 | Alta o cambio de un documento controlado |
| [plantilla_no_conformidad.md](./plantilla_no_conformidad.md) | NC-YYYY-NNN | 10.2 | Hallazgo (SonarQube, prueba, incidente) que exige acción |

No copiar texto normativo de los PDF de ISO. Solo códigos, responsables, entradas, salidas y enlaces al repo.
