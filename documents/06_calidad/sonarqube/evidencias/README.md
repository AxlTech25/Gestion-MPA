# Evidencias SonarQube

Una carpeta por corrida. Nombres = fecha + ID de función cuando el recorte sea por F-*:

```
evidencias/
  YYYY-MM-DD/
    registro.md
    quality-gate.png
    F-001.md
    F-014.png
```

La columna **SonarQube: Evidencia (Link GitHub)** de la matriz V4 apunta aquí, por ejemplo:

`https://github.com/AxlTech25/Gestion-MPA/blob/main/documents/06_calidad/sonarqube/evidencias/YYYY-MM-DD/registro.md`

No commitear tokens, JWT ni datos personales de producción.
