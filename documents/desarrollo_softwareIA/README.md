# Corpus — desarrollo de software con IA

Material de apoyo para la propuesta **Prompt-Centered SDLC v1.2**, validada con Sigemad MPA. Índice metodológico: [../metodologia.md](../metodologia.md).

Estos textos no son la metodología en sí: son el **estado del arte** con el que se argumenta por qué el SDLC debe rediseñarse cuando la IA comprime la implementación y Scrum deja de calibrar el trabajo.

| Archivo | Tipo | Uso en la propuesta |
|---------|------|---------------------|
| `Estado del arte para desarrollo de software con IA.docx` | Síntesis propia | Fichas de las seis fuentes |
| `_OceanofPDF.com_Generative_AI_for_Software_Developers_-_Saurabh_Shrivastava.pdf` | Libro (Shrivastava et al., 2025) | GenAI transversal al SDLC; ingeniería de prompts; supervisión humana |
| `A Comprehensive Review of Software Development Life Cycle methodo.pdf` | Artículo (Yas, Alazzawi y Rahmatullah, 2023) | Fases SDLC; Scrum como un modelo ágil más, no el único; no hay metodología universal |
| `AI Engineering.pdf` | Libro (Huyen, 2025) | Evaluación, guardrails y producción con modelos fundacionales |
| `ai-integration-in-software-development-and-operations-….pdf` | Libro (Krishna y Meda, 2024) | IA en DevOps, testing y SRE |
| `From Obstacles to Strategies-Integrating Artificial Intelligence into The Software Development Life Cycle.pdf` | Artículo (Paladino y Pons, 2025) | Barreras y estrategias al integrar IA en el SDLC |
| `The AI-Native Software Development Lifecycle.pdf` | Artículo (Hymel) | SDLC nativo de IA; modelo V-Bounce; menos tiempo en código, más en validar; sprints ágiles insuficientes |
